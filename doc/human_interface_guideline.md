# Design Guidelines

## Definitions

* Primary action: an action completes the dialog's main purpose.
    * Examples: Save, Create, Confirm etc.

* Related items: items that fit together semantically or functionally.
    * Examples: Label & input field, heading & description.

## Button order

Confirmation (primary action) is to be placed on the right, secondary buttons to the left.

## Padding and spacing

Padding is 0.25 for related and 0.375 for unrelated items.

## Focus order

Focus goes vfrom top to bottom, left to right.
