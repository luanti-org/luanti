# Design Guidelines

## Definitions

* Primary action: an action completes the dialog's main purpose. Examples: Save, Create, Confirm etc.

* Related items: items that fit together semantically or functionally. Examples: Label & input field, heading & description.

## Button order

Confirmation to the right, secondary buttons to the left

## Padding and spacing

0.375 for unrelated items, 0.25 for related items

## Focus order

Focus from top to bottom, left to right.
